# Ponytail Help

Ponytail is the "do less, but make it work" coding mode.

## Commands

- `ponytail`: implement with the simplest working approach.
- `ponytail lite`: small local change, minimal disruption.
- `ponytail full`: default; simplify while solving.
- `ponytail ultra`: challenge the premise and delete aggressively.
- `ponytail-review`: review a diff for over-engineering only.
- `ponytail-audit`: scan the repo for things to delete or simplify.
- `ponytail-debt`: list `ponytail:` comments.
- `ponytail-gain`: show the simplification scoreboard.

Prefer native tools, standard libraries, direct code, and deletion.
